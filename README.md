# ANFINI LOUNGE

暖炉のある談話室を、主観視点で歩けるブラウザ用の 3D 空間です（試作。ゲームの目的はまだありません）。
モデル、テクスチャ、照明、音はすべてコードで生成しています。画像や音声のファイルはありません。

公開先：https://wedgew00d.github.io/anfini-lounge/

## 遊び方

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | W A S D（SHIFT で早歩き） | 画面の左半分をドラッグ |
| 視点 | マウス | 画面の右半分をドラッグ |
| 操作 | E（またはクリック） | ACT ボタン |
| メニュー | ESC | 右上の II |

操作できる物

- 暖炉：熾火／ふつう／強火の切り替え（部屋の明るさと音も変わる）
- ランプ：点ける／消す
- ラジオ：BGM のピアノを流す／止める
- ソファ：座る（動くと立つ）

メニュー

- QUALITY：軽量／標準／高。PC は標準、スマホは軽量で始まります。
  - 軽量：アンビエントオクルージョン（AO）なし。接地の影は置き影のみ。影を落とすのは暖炉の光だけ
  - 標準：AO あり（半分の解像度）、輪郭は FXAA、ランプも影を落とす
  - 高：AO あり、マルチサンプル4倍、ランプも影を落とす
- FULLSCREEN：全画面の切り替え
- GRADE：カラーグレーディングの入切（影を青緑、光を橙に寄せる）
- SOUND、BGM と SE の音量（値はブラウザに保存）

窓の外の夜景は、部屋の中からはボケて見え、窓に近づくとピントが合います。

50fps を下回る状態が続くと、描画解像度を自動で下げます（最大で半分まで）。余裕が戻れば、一度だけ1段戻します。

## 構成

ビルドなしで、リポジトリ直下をそのまま配信します。

```
index.html        画面の枠、メニュー、スタイル
js/game.js        部屋、照明、操作、後処理
js/audio.js       音（Web Audio の合成）
lib/              three.js r170 と、後処理・AO・FXAA のモジュール（同梱）
```

## 確認用の機能

- F3 キー、または URL に `#debug` を付ける：左下に fps、位置、画質、描画解像度、自動調整の倍率、AO の入切、描画回数を表示
- ブラウザのコンソールから `window.ROOM`
  - `ROOM.pose(x, z, yaw, pitch)`：位置と向きの指定
  - `ROOM.fire(0〜2)`、`ROOM.lamp(true/false)`、`ROOM.sit(0/1)`、`ROOM.quality('low'|'mid'|'high')`
  - `ROOM.ao(4)`：AO だけを表示（`ROOM.ao(0)` で戻す）
  - `ROOM.grade(0/1)`：グレーディングの入切、`ROOM.haze(0/1)`：陽炎の入切
  - `ROOM.cfg({...})`：画質の設定を上書き、`ROOM.bench(n)`：n フレームを続けて描いた1フレームあたりの時間（ms）
  - `ROOM.state`：現在の状態
